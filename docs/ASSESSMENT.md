# Assessment and evidence

## Rating scale

Rate each dimension separately:
- 0: cannot yet explain or attempt.
- 1: succeeds with substantial hints.
- 2: succeeds independently on a familiar formulation.
- 3: succeeds independently on a fresh formulation and explains assumptions.

Dimensions: calculation, explanation, derivation, application, changed assumptions, transfer.

For a provisional gate, achieve at least 2 in every relevant dimension on fresh problems, with no unresolved core misconception. Confirm with an independent delayed transfer check approximately 7 days later. A failed delayed check reopens the topic. These are curriculum rules, not a scientifically validated measurement scale.

Do not average a serious conceptual gap away using arithmetic scores.

## Major gates

| Session | Gate |
|---|---|
| 12 | Translate a word problem into a function; interpret graphs, units and logs |
| 25 | Interpret matrix products and solve a small linear system; explain rank |
| 37 | Explain projection and least squares; interpret selected decomposition examples |
| 49 | Derive a derivative and use chain rule correctly |
| 59 | Explain gradients and calculate changes through a composite function |
| 70 | Reason with base rates, expectation and variance |
| 79 | Explain sampling uncertainty, leakage and evaluation assumptions |
| 90 | Derive an update and diagnose unstable or misleading learning |
| 100 | Independent mathematical defence and unfamiliar application |

Reviews between these gates include delayed checks on previous topics. Final confirmation can occur after Day 100.

## Final assessment

Split across sessions 98–100:
1. Regression: derive an objective, gradient and update for a tiny dataset.
2. Neural network: trace forward/backward calculations; explain chain rule, dimensions and nonlinearities.
3. Generalisation: critique a convincing-looking evaluation and repair it.
4. Transfer: formulate an unfamiliar problem, select a tool and justify its assumptions.
5. Defence: explain why the tool works, where leverage lies and what evidence could show it is inappropriate.

Separate correct calculations, sound assumptions and practical usefulness. Record partial success honestly; finish with a repair plan if the final gate is not passed.
