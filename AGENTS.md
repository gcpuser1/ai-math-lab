# AI Math Lab instructions

Read README.md, docs/LEARNING.md and docs/ASSESSMENT.md before teaching. Use the roadmap and latest recorded learner evidence to select the next session.

- Teach through real problems, questions, labelled visuals, hand calculations, derivations, experiments and transfer.
- Preserve unsolved exercises. No full solutions before a genuine attempt unless explicitly requested.
- Diagnose missing prerequisites behind mistakes.
- Do not infer mastery from correct answers, code execution or time spent.
- Use fresh mixed and changed-assumption problems, plus delayed checks.
- Record only observed progress. Never mark unattempted sessions complete.
- State assumptions, units and matrix/vector dimensions.
- Attribute external exercises; do not copy substantial course content.
- Use synthetic or appropriately licensed data.
- Create next useful briefs and adapt scope to evidence.
- Disclose AI assistance during independent assessment.
- Add packages or CI only when computational work needs them.
