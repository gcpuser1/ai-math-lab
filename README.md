# AI Math Lab

100 days of problem-driven mathematics for understanding machine learning.

## Goal

Independently explain, derive, calculate, question and apply the mathematics behind linear regression, gradient descent and backpropagation through a small neural network.

This is a mathematics-first foundation, not a promise of complete AI mastery. Plan for 14–18 hours per week (about 200–257 hours over 100 days). Repair prerequisites and reduce optional breadth when necessary.

## Start here

1. Read the [curriculum](docs/CURRICULUM.md) and [teaching agreement](docs/LEARNING.md).
2. Start the unsolved [Day 001 diagnostic](days/day001/README.md).
3. Use the [100-session roadmap](docs/ROADMAP.md).
4. Record evidence in [progress.csv](progress.csv), using the [session template](templates/session.md).
5. See the [resource review](docs/RESEARCH.md) for source selection and 2026 relevance.

## Learning loop

Real problem → predict → visualise → calculate → derive → experiment → explain → transfer.

Mathematical reasoning and exercises take roughly 80% of time; visual and computational experiments take 20%. Code checks reasoning after an attempt. An executable result alone does not demonstrate understanding.

## Completion

A session is complete when its evidence is recorded. A topic is mastered only after explanation, derivation, application, changed-assumption and delayed-transfer checks. A day number is a session identifier, not a deadline.

Only Day 001 is fully briefed initially. Future lessons are created from the roadmap and diagnostic results so prerequisite gaps can shape teaching.

No software installation is required to begin: use paper or a whiteboard. Later experiments use Python and NumPy when helpful.
